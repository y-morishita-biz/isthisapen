# this is a pen.

**Is this a pen?** ― ブラウザでペン軸の形を作り、3Dプリンタで刷って、市販のゲルインキ替芯を入れて使う、ペン軸ジェネレータです。

**サイト:** https://y-morishita-biz.github.io/isthisapen/

くびれの数・深さ・位置、断面のかたち(丸・三角・四角・六角・八角・花形)、ねじれ、太さ、キャップの形式(かぶせ・面一・なし)、先細りの長さ、転がり防止の平面を調整できます。形がペンとして成り立つと「This is a pen!」、成り立たないと「No, it isn't.」と答えます。

## 対応する替芯

直径 Ø6.2 mm・長さ 111 mm のゲルインキ替芯に合わせて設計しています。

| メーカー | 替芯 |
|---|---|
| 無印良品 | [ゲルインキボールペン替芯](https://www.muji.com/jp/ja/store/cmdty/detail/4550002822880) |
| 三菱鉛筆 | [UBR-Z-38](https://www.mpuni.co.jp/products/ballpoint_pens/refill_water_based.html?refill_code2=UBR-Z-38) |

替芯の3Dモデル(STEP)は [`models/refill-6.2x111.step`](models/refill-6.2x111.step) にあります。ジェネレータの寸法(座の位置、ペン先の穴、後ろ栓の位置)はこのモデルから決めています。

## 作り方

1. サイトで形を選び、「3MFを書き出す」を押します。軸・キャップ・後ろ栓が、立てた向きで1枚のプレートに並んでいます。
2. はじめてのときは「先端30 mmを試し刷り」で、替芯がすっと入るか確かめます。緩い・きついときは「替芯」の「すき間」を 0.05 mm ずつ変えます。
3. Bambu Studio や PrusaSlicer で開き、PLA・0.2 mm レイヤー・壁3周・インフィル15%・サポートなしで刷ります。
4. 替芯を後ろから入れ、後ろ栓をねじ込み、10円玉をスリットに当てて、栓の頭が軸の後端に当たるまで締めます(スリットは栓の頭を端から端まで貫通しています)。

栓とキャップの中心には通気穴があります。インクが出なくなるので塞がないでください。
